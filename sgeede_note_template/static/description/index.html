Note Template Configuration

Manage a library of reusable note templates from a dedicated configuration table. Set the template name, content, and where it applies.

Apply To Scope

Each template can be scoped to Sales only, Purchase only, or both giving you full control over where each note appears.

Configuration Menu

Templates are managed under Sales > Configuration or Purchase > Configuration no extra setup required.

Select Template Field

A dedicated Select Template field is added directly on the Sales Order and Purchase Order form for quick template selection.

Auto-fill Terms & Conditions

Selecting a template automatically populates the Terms & Conditions field. The note can still be freely edited after insertion.

Smart Domain Filtering

The template dropdown is automatically filtered by context. Sales orders only show Sales templates, Purchase orders only show Purchase templates.

Where do I find the Note Templates configuration?

You can find it under Sales > Configuration > Note Templates or Purchase > Configuration > Note Templates. From there you can create, edit, and manage all your templates.

How do I apply a template to a Sales or Purchase Order?

Open any Sales Order or Purchase Order and use the Select Template field. Once selected, the note content will automatically be inserted into the Terms & Conditions field.

Can I edit the note after selecting a template?

Yes. The template only pre-fills the Terms & Conditions field. You can freely edit the content after it has been inserted without affecting the original template.

Can I use the same template for both Sales and Purchase?

Yes. When creating a template, set the Apply To field to Both and it will be available in both Sales Orders and Purchase Orders.

Why don't I see certain templates in the dropdown?

The Select Template field is domain-filtered by context. Sales Orders only show templates scoped to Sales, and Purchase Orders only show templates scoped to Purchase or Both.
