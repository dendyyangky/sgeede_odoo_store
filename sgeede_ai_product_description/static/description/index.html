One-Click Generation

Click Generate with AI directly from the product form. No copy-pasting, no switching tabs, no external tools. The description is generated and ready to review without leaving Odoo.

100% Free AI Providers

Powered by Groq (Llama 3.3 70B) and Google Gemini Flash. Both providers offer a free tier with no credit card required. Configure your preferred provider once in Settings and use it across all products.

Tone and Language Control

Choose from 5 writing tones: Professional, Casual, Technical, Marketing, or Minimalist. Select output language between English or Auto. Settings are configurable per generation from the wizard.

Multi-Field Support

Generate descriptions for three different fields independently: Sales Description, Internal Notes, and eCommerce Description. Each field can have its own tone and style without affecting the others.

Preview Before Apply

Generated text appears in a preview panel before anything is saved. Review the result, regenerate for a new variation, or discard entirely. Nothing is written to the product until you confirm.

Odoo v17, v18 and v19 Compatible

Fully tested and compatible with Odoo v17, v18, and v19. Install once and it works across all supported versions with no additional configuration or version-specific adjustments needed.

Do I need to pay for the AI providers?

No. Both supported providers, Groq and Google Gemini, offer free tiers that do not require a credit card. You only need to create a free account and generate an API key from their respective consoles.

Where do I configure the API key?

Go to Settings and find the AI Product Description section. Enter your Groq or Gemini API key there. The key is stored securely in your Odoo database and is never exposed to the browser.

Does it overwrite my existing description automatically?

No. The result is shown in a preview panel first. Your existing description is only replaced after you click Use this to confirm.

Which product fields can be generated?

The module supports three fields: Sales Description, Internal Notes, and eCommerce Description. Each can be generated independently with different tone and language settings.
